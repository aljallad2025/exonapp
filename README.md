# تطبيق الطالب - أكاديمية إكسون (Flutter)

تطبيق موبايل للطلاب فقط، متصل مباشرة بنفس قاعدة بيانات Supabase المستخدمة في موقع
[exon-edu.com](https://exon-edu.com). أي بيانات (دروس، واجبات، إعلانات، جدول) تُدار من
لوحة تحكم الموقع تظهر تلقائيًا في التطبيق.

## ما تم بناؤه في هذه النسخة

- ✅ تسجيل الدخول (مطابق تمامًا لمنطق الموقع: فحص `status` = pending/inactive/active، وفحص أن الدور = student)
- ✅ Auto-login إذا كانت الجلسة محفوظة
- ✅ الشاشة الرئيسية + الإعلانات
- ✅ الدروس اليومية
- ✅ الواجبات المدرسية
- ✅ الجدول الدراسي
- ✅ الملف الشخصي + تسجيل الخروج

## شاشات لم تُبنَ بعد (يمكن إضافتها لاحقًا بنفس الطريقة)

- الرسائل (messages)
- المعرض (gallery_images)
- البرامج التعليمية (programs / my-courses)
- ما تم إنجازه (completed_tasks)
- الإشعارات (notifications)

## كيف تبنيه عبر Codemagic

1. ارفع هذا المجلد كاملاً إلى مستودع Git (GitHub/GitLab/Bitbucket) — مستودع خاص يُفضّل لأنه يحتوي مفتاح anon key.
2. سجّل دخول إلى [codemagic.io](https://codemagic.io) واربط المستودع.
3. Codemagic سيكتشف ملف `codemagic.yaml` الموجود بجذر المشروع تلقائيًا ويستخدمه كإعداد بناء.
4. لبناء APK اختبار سريع: اختر workflow باسم **"Exon Student App - Android"** واضغط Start build.
   (هذا البناء بدون توقيع Android حقيقي - يصلح للاختبار الداخلي فقط)
5. لبناء نسخة تُنشر على المتجر (Play Store / App Store)، ستحتاج:
   - إنشاء Keystore لأندرويد ورفعه في إعدادات Codemagic → Code signing identities
   - حساب Apple Developer + شهادة توقيع لـ iOS
   - عدّل `codemagic.yaml` بإضافة إعدادات التوقيع والنشر (راجع توثيق Codemagic الرسمي)

## تشغيل محلي (اختياري، إذا توفر Flutter SDK على جهازك)

```bash
flutter pub get
flutter run
```

## ⚠️ ملاحظات أمان مهمة

- مفتاح `anon key` الموجود في `lib/config/supabase_config.dart` **مصمم ليكون عامًا** (client-side) — الحماية الفعلية تأتي من صلاحيات RLS في Supabase، مش من إخفاء هذا المفتاح. هذا طبيعي وسليم.
- تأكد من أن صلاحيات RLS بجداول Supabase (`students`, `homeworks`, إلخ) تسمح فقط للطالب برؤية بياناته الخاصة — هذا موجود أصلاً في قاعدة البيانات الحالية.
- لا تضع أبدًا `service_role key` داخل تطبيق الموبايل تحت أي ظرف — هذا المفتاح للسيرفر فقط.
